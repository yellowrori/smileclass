초등학교 3학년 학생들의 자율성과 책임감을 길러주는 **학급 화폐 경제교실**과 칭찬 기반 **스마일(😊) 성장 게이미피케이션** 웹 애플리케이션입니다.

## 🚀 실행 방법 (초간단!)

별도의 서버 설치나 복잡한 설정 없이, **파일 하나만 더블클릭**하면 바로 실행됩니다.

1. 파일 탐색기에서 이 폴더의 **[`index.html`](file:///c:/Users/yello/Desktop/workspace/class/index.html)** 파일을 더블클릭합니다.
2. 크롬(Chrome)이나 엣지(Edge) 브라우저에서 아름다운 화면이 바로 열립니다.
3. 인터넷 연결이 없거나 오프라인 상태에서도 완벽하게 작동합니다.

## 💡 주요 기능 및 사용법

### 1. 상단 모드 전환 (로그인 없이 즉시 전환)
- **👩‍🏫 선생님 화면**: 교사 관리자 대시보드로 이동합니다.
- **🎒 학생 화면 선택 (드롭다운)**: 3학년 1반 20명의 학생 중 원하는 학생을 선택하면 해당 학생 시점으로 즉시 전환됩니다.

---

### 2. 👩‍🏫 교사 대시보드 화면
- **학급 요약 현황 카드**: 전체 학생 수, 학급 유통 총 화폐, 총 적립 스마일, 상점 구매 승인 대기 건수를 한눈에 확인합니다.
- **상점 승인 대기 배너**: 학생들이 상점에서 물품/쿠폰을 신청하면 알림 배너가 표시되며, `[승인하기]`(화폐 자동 차감 및 재고 반영) 또는 `[반려]`할 수 있습니다.
- **학생 20명 그리드 카드**:
  - 학생 번호, 귀여운 동물 아바타, 이름, 레벨(새싹/모험가/열매/달인/마스터), 1인 1역 배지 표시
  - **`[➕ 지급]` 버튼**: 발표, 배려, 청소 등 사유 프리셋을 원클릭으로 선택해 화폐와 스마일을 즉시 지급
  - **`[➖ 차감]` 버튼**: 규칙 위반이나 주의 시 화폐를 신속하게 차감
  - **`[🎒 시점]` 버튼**: 해당 학생의 시점 화면으로 바로 이동
- **퀵 관리 툴바**:
  - `[✨ 전체 일괄 지급]`: 학급 20명 전체에게 단체 보너스 지급
  - `[📋 1인 1역 주간 배정]`: 학생들의 주간 역할을 변경하거나 `[🎲 랜덤 자동 배정]` 실행
  - `[🛍️ 상점 물품 관리]`: 새로운 쿠폰이나 학용품/간식 등록 및 삭제
  - `[✅ 오늘의 미션 관리]`: 독서, 책상 정리 등 일일 체크리스트 미션 추가/삭제
  - `[🔄 데이터 초기화]`: 언제든 초기 20명 기본 샘플 데이터로 복원

---

### 3. 🎒 학생 개인 화면
- **내 프로필 히어로 배너**:
  - 큼직하고 귀여운 아바타와 칭호 배지 (예: `Lv.2 성장하는 모험가`)
  - **🪙 내 보유 화폐**: 반짝이는 골드 코인 카드
  - **😊 내 스마일 & 레벨 진행 바**: 다음 레벨까지 남은 스마일을 시각적으로 확인
- **탭 1: 📌 오늘의 할 일**:
  - **이번 주 나의 1인 1역**: 내 담당 역할(예: 칠판 지우미, 우유 급식 등)과 구체적인 임무를 확인하고 `[실천 완료하기]` 버튼을 누르면 축하 꽃가루 폭죽과 함께 보너스 획득
  - **오늘의 학급 체크리스트**: 교사가 등록한 미션을 체크하면 보상 지급
- **탭 2: 🛍️ 학급 상점**:
  - 자리 바꾸기 쿠폰, 급식 1등 줄서기 쿠폰, 보드게임 10분 이용권, 지우개/스티커 등 둘러보기
  - `[구매 신청하기]`를 누르면 선생님께 승인 요청 전송 (승인 대기 상태로 변경)
  - 상단에 내가 신청한 내역과 보유 중인 쿠폰 현황 표시
- **탭 3: 📜 내 활동 기록**:
  - 언제 어떤 사유로 화폐와 스마일을 받고 상점을 이용했는지 타임라인 확인

## 🎨 기술 및 디자인 특징
- **디자인**: 초등 3학년 눈높이에 맞춘 부드러운 카드 디자인, 선명하고 따뜻한 파스텔톤, 직관적인 이모지, 축하 컨페티(꽃가루 폭죽) 애니메이션 탑재
- **데이터 저장**: 웹 브라우저의 `LocalStorage`에 실시간 자동 저장되므로 새로고침하거나 브라우저를 껐다 켜도 데이터가 안전하게 유지됩니다.
